# 澄图 ClearFrame 使用说明

ClearFrame 在你的电脑上运行，通过本地网页操作。浏览器只连接本机服务；图像处理不使用 OpenAI API Key。依赖安装和动漫模型首次下载需要网络，准备好后可离线使用。

## 安装、打开与关闭

准备好 Windows 10/11 x64、Python 3.10–3.13（64 位）和现代浏览器。首次使用双击项目目录的 `Setup-ClearFrame.cmd`，等待 `.venv` 内的依赖安装完成。平时双击 `Start-ClearFrame.cmd`，浏览器会打开本地地址 `http://127.0.0.1:7866`。

双击启动器会在后台运行本地服务，启动器窗口可以自行关闭。关闭网页后服务仍在运行；点击页面「退出程序」才会停止服务，也会取消尚未完成的处理。不要在处理过程中删除 `.runtime`、`.models` 或结果目录。使用下面的命令行直接启动时，也可在该终端按 `Ctrl+C` 停止服务。

已有环境时可使用以下命令：

```powershell
# 打开服务并启动浏览器
.\.venv\Scripts\python.exe -m studio.server

# 不自动打开浏览器；另开地址 http://127.0.0.1:7866
.\.venv\Scripts\python.exe -m studio.server --port 7866 --no-browser
```

安装器检测到 NVIDIA 工具时安装 CUDA 版 PyTorch。若只需要 CPU 环境，可在 PowerShell 中运行 `./Setup-ClearFrame.cmd --cpu`；照片处理本身不会使用动漫模型。依赖缺失或启动失败时查看页面提示，以及 `.runtime/server.log`。

## 一张图片的完整流程

1. 将图片拖入导入区，或点击选择文件。可以一次导入多张，预览会自动切换到最新成功导入的图片，多张导入结束时选中最后一张。此时只创建本地工作副本。
2. 选择场景。二次元人物、二次元风景、实拍人像和实拍风景只是参数预设，程序不会判断内容，也不会把前景和背景分开处理。
3. 选择方法，阅读其「原理 / 可能效果 / 注意事项」。初次建议用「场景默认」或「轻柔保真」。
4. 调整强度和设备。设置变化不会启动任务，也不会立即改变已有结果。
5. 点击「处理当前图片」；需要批量计算时点击「处理全部图片」。进度区域显示当前阶段、进度与耗时；需要停止时点击取消。
6. 完成后切换原图、结果或对比视图，缩放至 100% 检查头发、眼睛、文字、皮肤与渐变等细节。分割线可拖动。
7. 选择下载 PNG。程序也会在自动保存目录保留单独命名的结果；原文件不会被覆盖。默认目录为项目的 `results/`，可以在右侧修改。

如果已有结果，改动参数后会继续显示上次完成的版本，并提示设置已变化。再次点击开始并等待成功后，预览才代表新设置。失败或取消不会把半成品标作成功结果。

常用输入格式为 PNG、JPEG、WebP、BMP、TIFF。只处理静态图片，动图需先导出一帧。单张文件上限 80 MB，尺寸至少 16×16，像素总量不超过 16,777,216；高位深图像转换到 8 位处理。

## 选择场景与方法

| 场景 | 初始强度 | 默认组合 | 建议先检查的细节 |
|---|---:|---|---|
| 二次元人物 | 40 | 动漫超分清理 + L0 | 发丝、眼睛、腮红、网点与小饰品 |
| 二次元风景 | 30 | 动漫超分清理 + L0 | 树叶、云层、细线建筑与远处文字 |
| 实拍人像 | 30 | 照片去噪 | 毛孔、睫毛、发丝和衣料 |
| 实拍风景 | 35 | 照片去噪 | 草叶、岩石、水纹与弱光纹理 |

| 方法 | 如何处理 | 适合的起点 | 可能的代价 |
|---|---|---|---|
| 场景默认 | 按场景选择组合 | 第一次试处理 | 预设不保证适合所有画风或噪声 |
| 轻柔保真 | 降低各阶段作用力度 | 人脸、细节多、只需少量清理 | 纹理或噪点可能残留 |
| 强化清理 | 动漫加强超分与 L0；照片去噪后轻锐化 | 明显细碎纹理 | 更容易损失细节；锐化可能放大残余噪点 |
| 自定义组合 | 手动勾选需要的阶段 | 对单个步骤做可控试验 | 叠加更多步骤不一定更好 |

自定义阶段按固定顺序执行：**照片去噪 → 动漫超分清理 → L0 平滑 → 锐化**。勾选顺序不会改变执行顺序。

| 阶段 | 基本原理 | 可能效果 | 主要局限 |
|---|---|---|---|
| 照片降噪 | 非局部均值（NLM）利用相似小区域的统计平均 | 降低颗粒和随机色彩噪声 | 也可能减弱皮肤、布料或草叶细节；不保证清除规则纹理 |
| 动漫重建 | 先缩小再用 Real-ESRGAN 动漫模型恢复，最后回到导入尺寸 | 减少密集细纹，使色块与线条更整齐 | 模型会推测细节，可能改变细线、眼睛或文字；照片可能出现绘画感 |
| L0 色块平滑 | 抑制较小梯度，减少细微颜色起伏 | 平整色块、压制部分细碎纹理 | 弱阴影、渐变、排线也可能被抹平或形成色阶 |
| 轻度锐化 | 增强局部边缘对比 | 让软化后的轮廓更清楚 | 无法找回已丢失的真实细节；可能产生光晕、锯齿或突出噪声 |

人像和风景照片默认不使用动漫模型或 L0。需要尝试时可在自定义组合里主动选择，并逐张比较；不要以「看起来更平滑」直接等同于「更准确」。

## 强度的含义

强度为 0–100，会影响算法参数和结果与原图的混合。它不是去噪成功率、画质分数或固定倍数，不同方法的相同数值不能直接比较。

- 0：保持导入后的图像像素不变，可用作基线。
- 默认值附近：适合开始试验；检查结果后再微调。
- 更高强度：可能压制更多噪声，也更容易损失纹理和改变微小结构。

输入解码、EXIF 方向规范化、色彩转换与 PNG 导出可能改变文件格式和元数据，所以强度 0 不代表导出文件与原文件逐字节一致。原始文件始终保留。

## 保存位置、队列导出与文件名

右侧「自动保存位置」提供「打开文件夹」和修改保存位置的入口。在设置框中粘贴文件夹的绝对路径（例如 `D:\图片\澄图结果`），保存后程序会检查目录是否可写，必要时创建目录，并记住选择。也可以恢复项目内的默认 `results/` 目录。

更改位置只影响之后提交的任务，已经运行或排队的任务仍保存到提交时的目录。已有结果不会被移动；它们的预览和下载仍指向原保存文件。启动时显式传入的开发测试目录优先，其次为页面持久设置；未设置过时才使用 `CLEARFRAME_OUTPUT` 环境变量或项目默认目录。

如果已记住的自定义目录暂时不可写（例如外接盘未连接），下次启动会提示原因并暂用项目默认目录，原目录偏好会保留。重新连接磁盘并再次启动可恢复该偏好，也可以直接在页面选择新位置。恢复默认的选择会跟随程序文件夹位置，不会记死旧项目路径。

队列的「一键导出最新结果」会在当前自动保存目录下创建独立的 `队列导出_年月日_时分秒` 文件夹，每张队列图片只复制最近一次成功处理的 PNG 和对应 JSON 记录。没有成功结果的图片会跳过，页面显示保存数量、跳过数量和目录，并可直接打开目录。正在重新处理的图片可以导出上次成功的结果；当前修改但尚未完成处理的参数不会改变已完成的结果。已经从当前队列移除的图片不会被收集。

新生成结果使用可读名称，例如：

- `爱丽丝_二次元人物_默认_强度40.png`
- `爱丽丝_二次元人物_轻柔_强度25.png`
- `爱丽丝_二次元人物_自定义-L0平滑+锐化_强度35.png`
- `爱丽丝_原图_强度0.png`

若已有同名 PNG 或 JSON，会递增为 `_02`、`_03`，不会覆盖。JSON 与 PNG 同名，记录完整参数和实际设备。导出时同名文件也会自动编号，JSON 保留原处理记录。已有旧版随机后缀文件不改名。

## 设备、进度和性能

自动选择会根据可用条件为支持 CUDA 的步骤选择设备；CPU 可在无受支持显卡时运行；GPU 选项用于动漫超分和 L0。**照片去噪及锐化使用 CPU**，所以即使选择 GPU，这些步骤也不会占用 GPU 计算。以任务显示的实际设备为准。

硬件面板显示实时 CPU、内存以及能够读取到的 NVIDIA GPU 利用率、显存和温度。系统指标反映整台电脑，其他程序也会影响这些数值；「不可用」代表没有读到数据，不等于 0。GPU 利用率低也不能单独证明未使用 GPU，短阶段可能在两次采样之间完成。

进度来自实际处理阶段、迭代或分块，并不保证线性增长，也不是剩余时间预测。解码、模型下载/加载、超分、平滑和保存的耗时差别较大；首次运行通常比后续运行慢。取消在安全检查点生效，正在执行的某些本机运算可能需要先返回。

RTX 5090 需要支持其架构的现代 CUDA 版 PyTorch 与合适的 NVIDIA 驱动。项目安装器配置独立 `.venv`，不复用旧版 PyTorch 1.x/CUDA 11.x。照片 CPU 路径不需要 PyTorch；使用动漫超分或 L0 前需要相应依赖。

## 文件与隐私

- `.runtime/`：导入图片的本地工作副本及自动保存目录设置。删除这个目录会重置页面保存的位置偏好。
- `results/`：默认自动保存位置，包含成功任务的 PNG 结果与对应 JSON 处理记录。页面可修改位置，`CLEARFRAME_OUTPUT` 只在没有页面持久设置时作为默认值。
- `.models/`：本地动漫模型缓存。通过 `CLEARFRAME_MODELS` 环境变量可指定其他目录。
- `.venv/`：项目独立 Python 依赖。

动漫模型只在需要时下载，不需要把图片发给模型服务器。安装依赖、获取模型等网络连接与图像处理是不同环节；离线使用前需先备齐所选方法的依赖和模型。

输出保留导入后的宽高与透明通道，尽可能保留适用的 RGB ICC 信息，统一保存为 PNG。不要把它当作 RAW、HDR、多帧动画或原格式元数据保全工具。清理本地副本前先确认所需结果已另存。

## 常见情况

**导入或调节后没有开始处理。** 这是设计行为。检查设置，然后点击开始。

**GPU 可见，任务仍显示 CPU。** 照片去噪和锐化本来就在 CPU 上运行。动漫步骤还需兼容的 CUDA PyTorch；查看任务错误与安装器输出。

**第一次进度停留在下载或加载模型。** 检查网络和磁盘空间，等待该阶段结束。模型备齐后无需每次下载。

**脸变平、细字变形、发丝变少。** 降低强度，选择轻柔，或在自定义组合中移除动漫超分/L0。用原图对比决定是否保留结果。

**内存不足或处理过慢。** 先关闭占用显存的其他程序，改用较轻方法或较小图片。切到 CPU 可避免某些显存限制，但可能更慢，且仍会使用系统内存。

**页面提示结果来自旧设置。** 当前预览是上次成功结果。点击开始才会按现在的设置重新计算。

当前 ClearFrame 界面没有上游的保护笔刷、磁性套索或局部分割。上游文档中的这些功能和旧入口自动处理行为，不代表本工作台的功能。
