# 澄图 ClearFrame

一个手动操作的本地图像处理工作台，基于 [gpt-anime-denoise](https://github.com/CXP-2024/gpt-anime-denoise) 改造。拖入图片、选择场景与处理方法、调节强度，再点击开始；处理完成后可查看结果、拖动分割线对比原图并保存 PNG。

**拖入图片和修改设置都不会开始处理。** 图片在本机计算，不需要 OpenAI API Key，也不调用图像生成服务。当前交付为 Windows 本地网页程序：双击启动器后在浏览器使用，后台由项目自己的 Python 环境运行。

## 开始使用

1. 首次使用，双击 `Setup-ClearFrame.cmd`，安装项目目录内的 `.venv` 依赖。安装依赖和首次下载动漫模型需要联网。
2. 双击 `Start-ClearFrame.cmd`，浏览器打开 `http://127.0.0.1:7866`。
3. 拖入图片或点击导入，预览自动切换到新图片；选择场景、方法和强度，然后点击开始处理。
4. 完成后切换「原图」「结果」「对比」查看。结果默认自动另存到 `results/`，右侧可打开或更改保存目录；也可下载单张结果，或一键把当前队列每张图的最新成功结果导出到独立文件夹。
5. 使用完毕，点击页面「退出程序」停止本地服务；只关闭网页不会停止后台。

要求 Windows 10/11 x64、Python 3.10–3.13（64 位），以及现代浏览器。照片基础去噪可只用 CPU；动漫模型可用 CPU 或受支持的 NVIDIA CUDA 显卡。RTX 5090 需要支持其架构的现代 CUDA 版 PyTorch 与合适的驱动，旧版 PyTorch 1.x/CUDA 11.x 不适用。请使用本项目安装器配置的独立环境，无需修改其他项目的 Python。

依赖已安装时，也可在项目目录启动：

```powershell
.\.venv\Scripts\python.exe -m studio.server
```

## 场景与方法

场景是供人选择的参数预设，不会自动识别、分割人物或背景。

| 场景 | 默认处理 | 起始强度 |
|---|---|---:|
| 二次元人物 | 动漫超分清理 + L0 平滑 | 40 |
| 二次元风景 | 动漫超分清理 + L0 平滑 | 30 |
| 实拍人像 | 保守的非局部均值去噪 | 30 |
| 实拍风景 | 保守的非局部均值去噪 | 35 |

「场景默认」按场景组合；「轻柔保真」减少改动；「强化清理」加大清理力度，照片场景采用去噪与轻度锐化；「自定义组合」可选择照片降噪、动漫重建、L0 色块平滑、轻度锐化。页面显示每种方法的基本原理、预期效果和局限。

强度范围 0–100，它是处理参数与原图混合程度的控制量，不是画质分数。0 保持导入后的图像像素不变。强度增大可能抹掉发丝、皮肤、布料、小字和细渐变；动漫模型也可能重新推测细节。没有对所有图片都最好的方法，建议从默认值或轻柔开始，在 100% 尺寸下对比。

## 工作台功能

- 多图导入与逐张设置，可手动处理当前图片或全部图片，明确点击才提交处理。
- 自动选中新导入的图片；保存目录可修改并记住，提供直接打开文件夹的按钮。
- 队列最新结果批量导出到独立目录；文件名包含场景、处理方式与强度，同名自动编号，不覆盖已有文件。
- 真实阶段进度、耗时、取消与错误提示；首次模型下载显示在进度阶段中。
- CPU、内存、GPU 利用率、显存与温度面板；无法读取的指标显示为不可用。
- 自动 / GPU / CPU 设备选择，结果记录实际执行设备。照片去噪与锐化在 CPU 上执行，选择 GPU 不会把这些步骤变成 GPU 算法。
- 原图、结果、滑杆对比、缩放与 PNG 下载；修改参数后保留上次结果，需再次开始才会生成新结果。
- 原文件不覆盖，保留导入后的尺寸和透明通道；导出为 PNG，不等同于原格式或元数据的无损复制。

## 本地文件与离线使用

| 路径 | 内容 |
|---|---|
| `.venv/` | 本项目独立 Python 环境 |
| `.models/` | 首次使用时下载的动漫模型；可用 `CLEARFRAME_MODELS` 指定其他目录 |
| `.runtime/` | 导入图片的本地工作副本和保存目录偏好 |
| `results/` | 默认 PNG 结果与 JSON 记录目录；可在页面修改，`CLEARFRAME_OUTPUT` 用于尚无页面设置时的默认位置 |

模型与依赖准备好后可离线运行；照片基础去噪不需要下载动漫模型。处理结果和导入副本可能包含你的私人图片，请按自己的需要清理本地目录。

详见[使用说明](docs/USER_GUIDE.md)。当前界面不包含上游的局部保护笔刷或套索；上游旧入口仍保留在源码中，使用本工作台请打开 `Start-ClearFrame.cmd`。

已完成的功能检查、RTX 5090 实测耗时及验证边界见[验证记录](docs/VALIDATION.md)。
